01 / PROJECT

About Health360

Health360 presents descriptive analysis of diabetes, related health indicators, lifestyle patterns, and healthcare access through interactive visualizations.

02 / DATA

Dataset & tools

Data: 2015 Behavioral Risk Factor Surveillance System (BRFSS) health indicators dataset.

Python · Flask · Tableau Public · GitHub

03 / INTERPRETATION

Important limitations

Survey responses are self-reported. These charts show associations, not causation, and should not be used as individual medical advice.
