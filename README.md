# Health360 — Chronic Disease Risk Analysis

## Overview
Health360 is a data analytics project that explores relationships between diabetes and lifestyle, demographic, and health indicators using Tableau Public and the 2015 Behavioral Risk Factor Surveillance System (BRFSS) dataset.

## Objectives
- Explore diabetes prevalence across age groups.
- Examine associations between diabetes and BMI, high blood pressure, and high cholesterol.
- Analyze lifestyle indicators such as smoking, physical activity, alcohol consumption, and vegetable consumption.
- Explore healthcare access indicators across income groups.
- Present findings through interactive Tableau dashboards.

## Tools and Technologies
- **Tableau Public** — data visualization and interactive dashboards
- **GitHub** — project documentation and version control
- **BRFSS 2015** — public health survey dataset

## Key Performance Indicators
The analysis includes diabetes prevalence, high blood pressure prevalence, and high cholesterol prevalence.

## Dataset
The project uses the Diabetes Health Indicators dataset derived from the 2015 BRFSS survey. The indicators are based on survey responses and should not be interpreted as individual clinical diagnoses.

## Limitations
This is an observational, self-reported survey analysis. The visualizations show patterns and associations, not proof that a lifestyle factor causes a disease. Results may also be affected by self-reporting and other confounding factors.
